This project analyzes retail sales data from a CSV file using Python.

Files:
Retail_sales_data_analyzer.py
retail_sales.csv

Libraries used:
pandas
numpy
matplotlib
seaborn

Run:
python Retail_sales_data_analyzer.py

When asked for the file name, enter:
retail_sales.csv

The program:
loads the dataset
checks for missing values
calculates total and average sales
filters data by category
shows a summary
creates a bar chart, line graph, and heatmap
