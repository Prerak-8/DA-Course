# Multi-Utility Toolkit

This project is made in Python using modules and a menu system.

It includes:
- datetime and time operations
- math operations
- random data generation
- UUID generation
- file handling
- module attribute checking with dir()

## Files
- project7.py
- modules/datetime_utils.py
- modules/math_utils.py
- modules/random_utils.py
- modules/uuid_utils.py
- modules/file_utils.py

## How to run
Run project7.py from Python.

## About the project
Each module has separate functions and the main file links everything together through the menu.
